# 电视节目经营周报（公开汇总展示）

这是电视节目运营的只读周报。网页数据截止 2026-10-16；仅使用节目场次层面的脱敏经营数据。不存在客户姓名、电话、微信号；单项“客户人数”或“扫码人数”并不保证跨场次去重。首页仅展示经营数据，数据核验在独立栏目。

网页导入数据只保存在访问者本机浏览器，尚不支持多人在线协作编辑。

## V1.8 每5分钟扫码走势

在 V1.7 移动底部四栏导航提交 `4eaee76` 上继续开发，保留四个一级入口。首页快捷卡及「场次图表」顶部可进入分时走势；原有四图与明细保留在相邻切换区。

本轮重新核对用户提供的《电视节目数据.xls》（111104字节，SHA-256 `ad34b8fa4352557e793d64bdc524679476cd99d58fc0fdc3de8093c3508f51b3`）。五个节目工作表的 **C列是分段扫码添加企微人数，D列是合并合计**。16场共96段均有数值，逐段区间连续且长5分钟，不能将D列重复作为增量。此前“原表无法重建5分钟走势”的判断已更正。

每场可追溯到时间单元格、人数单元格及合计单元格，脱敏证据见 `data/five-minute-source.json`。未公开原工作簿及其中客户明细。时间以首个扫码区间起点记作0分钟，未取得正式节目单，不将此起点冒充核实后的开播时刻。

- 16场扫码总量仍为1342人次，30分钟内1256人次、后续86人次。五线路实付累计仍为489071元。
- 清远肇庆10/4：D33:D40覆盖40分钟，19人；C33:C38前30分钟17人，C39:C40后续2人。福建泰宁10/10的D33:D40也跨40分钟，后10分钟为0，30分钟合计仍10人。
- 支持最多3场并排比较、同刻度折线/柱状图、六段精确数字、来源展开。手机图形及卡片可横向滚动。
- 分时CSV模板在分时区下方下载，六段留空；缺测不能填0。验证六段独立增量、非负整数、完整来源、唯一场次及两层合计后才保存。导入失败整批不写入；仅存本浏览器。
- 旧浏览器缓存若完全匹配10/4原内置的19+0记录，会按本轮原表证据修正为17+2；其余自定义数据不会套用不匹配的内置分段。

运行计算与导入回归检查：`node --test tests/five-minute.test.cjs`。浏览器尺寸验收在真实Chrome引擎完成，不等于iPhone/Android微信真机验收。
